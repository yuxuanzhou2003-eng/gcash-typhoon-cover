## Design Context

### Users
CLIMADA platform operations staff and course-project reviewers, using a desktop workbench to inspect merchant typhoon exposure, review evidence and approve simulated payout batches. There is no merchant-facing enrolment app.

### Brand Personality
Calm, precise and operational. The user explicitly selected the local Foresail interface as the visual reference.

### Aesthetic Direction
Use the actual Foresail Freight Studio design, not an independently interpreted "Foresail-inspired" style. The user confirmed the live case workspace at https://fore-sail.vercel.app/cases/CASE-001, specifically its workflow timeline, capsule tabs, and soft content panels.

Reference source: `D:/2 Archive 独立项目/ai探险记/Hackathon/Sup Build2026-ForeSail/ForeSail/frontend/src/styles/theme.css`, `styles/fs2-overview.css`, and `components/WorkflowStepper.tsx`.

Match the #EBEDF1 canvas, #FAFBFD cards, #2C323B ink, #2E3542 dark capsule selection, #747B88 secondary text, #5F7FD0 blue and #67A08E green. Use Plus Jakarta Sans, borderless 20–26px cards with soft shadows, capsule buttons and tabs, and a centered dot-and-line workflow timeline. Keep the hierarchy: context → workflow → capsule tabs → content. Preserve the approved dark geographic map. Avoid trade-specific vocabulary, decorative dashboard metrics, implicit sample data and nonfunctional navigation.

### Design Principles
- One authoritative dataset connects the portfolio, map, actions and ledger.
- Start empty; sample datasets load only through an explicit action.
- Show source, time and simulation status without overwhelming the workflow.
- Surface a clear next action; reveal technical evidence on demand.
- Prefer direct operational instructions. Omit promotional taglines and decorative labels that repeat a nearby heading, status or navigation item.
- Support keyboard focus, readable contrast, narrow screens and reduced motion.
